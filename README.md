# Memory game

## Ссылка на проект

[![GitHub Pages](https://img.shields.io/badge/-GitHub%20Pages-blue?style=flat-square)](https://Artynskij.github.io/memory-game/)

Классическая игра на память (Memory), где всё игровое поле, карточки и модальные окна **формируются динамически через JavaScript**. В HTML нет готовой разметки — только контейнер-обёртка, в который скрипт собирает интерфейс.

## 🎮 Как играть

1. Нажмите на карточку — она перевернётся и покажет картинку.
2. Откройте вторую карточку.
3. Если картинки совпали — обе остаются открытыми.
4. Если нет — карточки переворачиваются обратно через 800 мс.
5. Цель: найти все пары за минимальное количество ходов.

## 🚀 Функциональность

- **Случайная выборка картинок** — из базы данных выбираются 8 случайных изображения, дублируются и перемешиваются (16 карточек).
- **Проверка пар** — сравнение карточек по `data-id`, подсветка совпавших.
- **Блокировка кликов** — пока идёт проверка пары, игрок не может открыть третью карточку.
- **Счётчик ходов** — каждый клик по карточке увеличивает счётчик.
- **Таблица лидеров** — топ-10 результатов, отсортированных по ходам, затем по дате.
- **Модальное окно победы** — появляется при нахождении всех пар, с кнопками «Новая игра» и «Закрыть».
- **Новая игра** — сброс поля и генерация новой раскладки.

## 🛠️ Технологии

- **HTML** — только body.
- **CSS** — Grid для поля, 3D-трансформации для переворота карточек, медиазапросы для адаптива.
- **JavaScript (ES-модули)** — классы `Game`, `Card`, `Body`, `Modal`, логика разделена по файлам.
- **localStorage** — хранение результатов между сессиями.
